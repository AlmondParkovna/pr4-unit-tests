## Опис

Функція `lateFee(days, daily)` обчислює плату за прострочення.

- Плата дорівнює кількості днів, помноженій на денну ставку.
- Максимальна плата — 100 грн.
- Нуль днів дає 0 грн.
- Від'ємна кількість днів, дробові дні або від'ємна денна ставка спричиняють помилку.
